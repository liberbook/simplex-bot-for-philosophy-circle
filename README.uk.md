Бот [SimpleX Chat](https://simplex.chat) для філософського гуртка. Він зберігає
файли, якими ділиться група, веде щотижневі заняття та їхній розклад, проводить
голосування й відповідає на запитання про «Етику» Спінози. Node >= 22, без
npm-залежностей, на власному сервері, з наскрізним шифруванням, як будь-який чат SimpleX.

Зроблений для книжкових клубів, семінарів і навчальних груп: скан, роздатковий
матеріал і запис кожного заняття лежать в одному місці, найближче заняття видно
на картці, і нікому не треба гортати чат за рік, щоб знайти файл.

```text
 група #ethics                         особиста бесіда з ботом
 ─────────────────────────────         ────────────────────────────────
 будь-який файл    зберігається тихо   /files            архів
 conatus (відповіддю) ──► файл   ──►   /get 3            надішли ось цей
 prius  (під записом)                  /class            найближче заняття
 /spinoza          довідка особисто    /class schedule sat 12:15
 /spinoza class 19.09 Субстанція       /vote  /ethics  /watch
```

У групі бот — тихий учасник: мовчки зберігає кожен файл, прив'язує допис до
заняття й відповідає одним рядком. Усе інше — списки, завантаження, перенесення
заняття, чернетка голосування — відбувається в особистій бесіді. На звичайну
розмову бот не відповідає, навіть якщо в ній є слово-тригер; на прохання про
файл словом `conatus` він знову викладає файл у відповідь на прохання, коротко
додаючи, що файл є й в особистій бесіді, і надсилає його туди.

## Що він уміє

| | |
| --- | --- |
| **Файли** | мовчки зберігає кожен файл, надісланий у групу; слово-тригер (`conatus`) у відповідь на файл знову викладає його в групу й надсилає вам особисто; показує список, надсилає файл за номером чи назвою, переносить видалені до кошика на 30 днів, стежить за лімітом місця |
| **Заняття** | одна картка на заняття: дата, тема, завдання, матеріали й запис; щотижневе правило, перенесення, скасування та нагадування в групі перед початком |
| **Голосування** | готуються особисто, публікуються одним повідомленням у групі, голосують реакціями; відкриті, доки автор їх не закриє або 8 днів ніхто не голосує, або до терміну, заданого `--days` |
| **Етика** | відкриває будь-яке місце за ідентифікатором, шукає в тексті, показує будову частини — корпус узято з російського перекладу «Етики» |

Кожна команда з відповіддю, яку вона справді дає, — у
[INTERFACE.md](INTERFACE.md) (генерується з коду, англійською). Як влаштована
кожна функція і де вона в коді: [FEATURES.md](FEATURES.md). Шари та карта
модулів: [ARCHITECTURE.md](ARCHITECTURE.md).

Потрібні лише файли й голосування? [conatus](https://github.com/liberbook/simplex-bot-for-reading-circle) — молодший брат:
зберігає кожен файл, повертає його за словом і проводить голосування — і нічого більше.

## Запуск

```bash
cd deploy
mkdir -p data && cp spinoza.example.json data/spinoza.json   # група, мова, тригер, ліміт
docker compose up -d --build
docker compose logs -f      # адреса бота: `address: https://…` (також у data/state/address.txt)
```

Під'єднайтеся до цієї адреси із застосунку SimpleX, потім запросіть бота до своєї
групи — це може зробити лише адміністратор бота. Покроково, разом із власними
релеями та оновленнями: [INSTALL.md](INSTALL.md) (англійською).

Щоб бот говорив українською, вкажіть `"language": "uk"` у `spinoza.json`.

## Налаштування

`spinoza.json` поруч із ботом (або `--config`), змінні середовища `SPINOZA_*`,
прапорці командного рядка; пізніше джерело перемагає. `node src/main.js --help`
перелічує всі.

| ключ | за замовчуванням | значення |
| --- | --- | --- |
| `group` | `*` | які групи обслуговувати (шаблон) |
| `trigger` | `conatus` | слово, яке у відповідь на файл (або одразу після нього) знову викладає файл у групу й надсилає його особисто; зберігаються всі файли в будь-якому разі |
| `language` | `en` | `en`, `ru`, `uk`, `it` — мова всього, що каже бот |
| `timezone` | `Europe/Moscow` | часовий пояс розкладу |
| `adminSecret` | немає | `/admin <секрет>` робить учасника адміністратором бота |
| `maxStorage` | `100gb` | ліміт розміру архіву |
| `membersOnly` | `true` | видавати файли лише учасникам групи |
| `reminderMinutes` | `30` | за скільки хвилин нагадувати групі про заняття, `0` — вимкнено |

## Мови

Усе, що каже бот, лежить по одному файлу на мову в [src/i18n/](src/i18n/):
[en.js](src/i18n/en.js) — шаблон, у [ru.js](src/i18n/ru.js),
[uk.js](src/i18n/uk.js), [it.js](src/i18n/it.js) рівно ті самі ключі.

Щоб додати мову: скопіюйте `en.js`, перекладіть значення, імпортуйте файл у
[src/bot/replies.js](src/bot/replies.js) і додайте його до таблиці мов там само.
Більше ніде в коді мова не згадується, а `npm test` перевірить ваш файл на
пропущені ключі й невідмальовані тексти.

Команди не перекладаються: `/files`, `/class`, `/vote`, `/ethics` та їхні
російські форми (`/файлы`, `/занятие`, `/голосование`, `/этика`, `/ф /з /г /э`)
розпізнаються будь-якою мовою відповідей. Корпус «Етики» — російський переклад,
тому цитати лишаються російськими будь-якою мовою.

Текст узято з [Ethica Explorer](https://liberbook.github.io/ethica-explorer/) ([вихідний код](https://github.com/liberbook/ethica-explorer)): уся «Етика» на одній інтерактивній
сторінці, де кожне посилання Спінози розкривається просто в тексті, з повними ланцюжками доведень і
мапою всіх залежностей. Його збірка звіряє кожне посилання з латиною 1677 року й вивантажує корпус,
яким користується бот (`data/spinoza_ethica_index_ru.json`).
