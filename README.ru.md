Бот [SimpleX Chat](https://simplex.chat) для философского кружка. Он хранит
файлы, которыми делится группа, ведёт еженедельные занятия и их расписание,
проводит голосования и отвечает на вопросы об «Этике» Спинозы. Node >= 22, без
npm-зависимостей, на своём сервере, со сквозным шифрованием, как любой чат SimpleX.

Сделан для книжных клубов, семинаров и учебных групп: скан, раздаточный материал
и запись каждого занятия лежат в одном месте, ближайшее занятие видно на
карточке, и никому не нужно листать чат за год, чтобы найти файл.

```text
 группа #ethics                        личная беседа с ботом
 ─────────────────────────────         ────────────────────────────────
 любой файл        хранится молча      /файлы            архив
 conatus (ответом) ──► файл      ──►   /дай 3            пришли вот этот
 prius  (под записью)                  /занятие          ближайшее занятие
 /spinoza          справка лично       /занятие расписание сб 12:15
 /spinoza занятие 19.09 Субстанция     /голосование  /этика  /уведомления
```

В группе бот — тихий участник: молча сохраняет каждый файл, привязывает пост к
занятию и отвечает одной строкой. Всё остальное — списки, скачивание, перенос
занятия, черновик голосования — происходит в личной беседе. На обычный разговор
бот не отвечает, даже если в нём есть слово-триггер; на просьбу о файле словом
`conatus` он заново выкладывает файл ответом на просьбу, коротко добавляя, что файл
есть и в личной беседе, и присылает его туда.

## Что он умеет

| | |
| --- | --- |
| **Файлы** | молча хранит каждый файл, выложенный в группе; слово-триггер (`conatus`) ответом на файл заново выкладывает его в группу и присылает вам лично; показывает список, присылает файл по номеру или имени, переносит удалённые в корзину на 30 дней, следит за лимитом места |
| **Занятия** | одна карточка на занятие: дата, тема, задание, материалы и запись; еженедельное правило, перенос, отмена и напоминание в группе перед началом |
| **Голосования** | готовятся лично, публикуются одним сообщением в группе, голосуют реакциями; открыты, пока автор их не закроет или 8 дней никто не голосует, или до срока, заданного `--дней` |
| **Этика** | открывает любое место по идентификатору, ищет по тексту, показывает строение части — корпус взят из русского перевода «Этики» |

Каждая команда с ответом, который она действительно даёт, — в
[INTERFACE.md](INTERFACE.md) (генерируется из кода, на английском). Как
устроена каждая функция и где она в коде: [FEATURES.md](FEATURES.md). Слои и
карта модулей: [ARCHITECTURE.md](ARCHITECTURE.md).

Нужны только файлы и голосования? [conatus](https://github.com/liberbook/simplex-bot-for-reading-circle) — младший брат:
хранит каждый файл, возвращает его по слову и проводит голосования — и ничего больше.

## Запуск

```bash
cd deploy
mkdir -p data && cp spinoza.example.json data/spinoza.json   # группа, язык, триггер, лимит
docker compose up -d --build
docker compose logs -f      # адрес бота: `address: https://…` (он же в data/state/address.txt)
```

Подключитесь к этому адресу из приложения SimpleX, затем пригласите бота в свою
группу — это может сделать только администратор бота. По шагам, включая свои
релеи и обновления: [INSTALL.md](INSTALL.md) (на английском).

Чтобы бот говорил по-русски, укажите `"language": "ru"` в `spinoza.json`.

## Настройки

`spinoza.json` рядом с ботом (или `--config`), переменные окружения `SPINOZA_*`,
флаги командной строки; более поздний источник побеждает. `node src/main.js
--help` перечисляет все.

| ключ | по умолчанию | значение |
| --- | --- | --- |
| `group` | `*` | какие группы обслуживать (шаблон) |
| `trigger` | `conatus` | слово, которое ответом на файл (или сразу после него) заново выкладывает файл в группу и присылает его лично; хранятся все файлы в любом случае |
| `language` | `en` | `en`, `ru`, `uk`, `it` — язык всего, что говорит бот |
| `timezone` | `Europe/Moscow` | часовой пояс расписания |
| `adminSecret` | нет | `/admin <секрет>` делает участника администратором бота |
| `maxStorage` | `100gb` | лимит размера архива |
| `membersOnly` | `true` | выдавать файлы только участникам группы |
| `reminderMinutes` | `30` | за сколько минут напоминать группе о занятии, `0` — выключено |

## Языки

Всё, что говорит бот, лежит по одному файлу на язык в [src/i18n/](src/i18n/):
[en.js](src/i18n/en.js) — шаблон, у [ru.js](src/i18n/ru.js),
[uk.js](src/i18n/uk.js), [it.js](src/i18n/it.js) ровно те же ключи.

Чтобы добавить язык: скопируйте `en.js`, переведите значения, импортируйте файл в
[src/bot/replies.js](src/bot/replies.js) и добавьте его в таблицу языков там же.
Больше нигде в коде язык не упоминается, а `npm test` проверит ваш файл на
пропущенные ключи и неотрисованные тексты.

Команды не переводятся: `/files`, `/class`, `/vote`, `/ethics` и их русские
формы (`/файлы`, `/занятие`, `/голосование`, `/этика`, `/ф /з /г /э`) понимаются
на любом языке ответов. Корпус «Этики» — русский перевод, поэтому цитаты остаются
русскими на любом языке.

Текст взят из [Ethica Explorer](https://liberbook.github.io/ethica-explorer/) ([исходный код](https://github.com/liberbook/ethica-explorer)): вся «Этика» на одной интерактивной
странице, где каждая ссылка Спинозы раскрывается прямо в тексте, с полными цепочками доказательств и
картой всех зависимостей. Его сборка сверяет каждую ссылку с латынью 1677 года и выгружает корпус,
которым пользуется бот (`data/spinoza_ethica_index_ru.json`).
